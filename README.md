# Doors

**Live:** https://vishnuvsdevtech.github.io/doors/

Navigation as a doorway. Sections are doors, not links. Clicking swings a panel on a left hinge through 104 degrees, revealing a room that was already lit behind it.

**How:** The content is hidden until the door moves, so the click has a consequence you can feel. One door opens at a time — closing the previous one is what makes the next feel like arriving somewhere.

**What it is not:** Not a router and not an animation library: one CSS transform and a class toggle.
